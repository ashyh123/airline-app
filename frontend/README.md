# 机场加油车调度指挥台

React + Material UI 的调度指挥前端。执行 `yarn install` 和 `yarn start` 后访问开发服务器地址；默认与 `http://127.0.0.1:8080/api` 的本地调度服务通信，可通过 `VITE_API_BASE` 环境变量调整。

本项目的布局、主题与基础组件衍生自 [Mantis Free React Material UI Dashboard Template](https://github.com/codedthemes/mantis-free-react-admin-template)。原项目按 MIT License 发布，完整许可证见 `LICENSE`。
